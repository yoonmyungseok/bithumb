# Antigravity 프로젝트 공통 규칙

이 파일은 Antigravity 워크스페이스 전용 규칙의 진입점이다. Antigravity의 Rules 화면에서 이 규칙을 `Always On`으로 설정한다.

아래 공통 규칙을 먼저 적용한다.

@../../AGENTS.md

작업 유형별 세부 규칙은 루트 `AGENTS.md`의 필독 문서 표에 따라 확인한다. 다음 문서는 항상 함께 확인한다.

@../../docs/agent-rules/trading-safety.md
@../../docs/agent-rules/exchange-isolation.md
@../../docs/agent-rules/testing-reporting.md

전략 또는 대시보드 작업일 때는 `AGENTS.md`가 지정한 `strategy-change.md` 또는 `dashboard-operations.md`도 반드시 읽는다.
